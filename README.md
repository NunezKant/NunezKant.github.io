# miguelno.github.io

Personal portfolio site for **Miguel A. Núñez Ochoa** — Computational Neuroscientist & ML Scientist.

Built as a single-file static site (`index.html`). No build step. No framework.

**Live at:** https://nunezkant.github.io *(update this once deployed)*

---

## Running locally

Just open `index.html` in any browser. Or use a local server:

```bash
npx serve .
# → http://localhost:3000
```

## Deploying

Push to the `main` branch of a repo named `NunezKant.github.io`. GitHub Pages serves it automatically at `https://nunezkant.github.io`.

See `CLAUDE.md` for full design system, content rules, and deployment notes.
